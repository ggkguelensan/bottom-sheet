Как будет устроен Shell Sheet

В целевом состоянии приложение принимает бизнес-решение, Core фиксирует его identity и lifecycle, а один DOM coordinator превращает новый target в непрерывное визуальное состояние — без второго source of truth.

  • 01 authoritative owner — приложение
  • 02 runtime loop: semantic и hot visual
  • 03 независимых региона: Header / Body / Footer
  • 05 пакетов с жёсткими ownership-границами
Это ненормативный визуальный отчёт по состоянию origin/main @ 154f515. При любом расхождении единственным источником истины остаётся specs/README.md и связанные спецификации.
01 / NORTH STAR

Три несущих принципа

Target-архитектура строится вокруг ясного ownership: домен решает, Core упорядочивает, DOM визуализирует.

Authority Target приходит снаружи и целиком

Открытие, snap point, presentation, modality, draggable policy и region keys меняются одной транзакцией приложения.

Coordination Один visual coordinator

Геометрия Popup, Backdrop и изменившиеся регионы стартуют в одном кадре и получают один tokenized terminal result.

Continuity Прерывание — штатный путь

Новый target начинает движение от текущей видимой геометрии. Late completion старой анимации не может settle новый переход.

03 / ATOMIC TARGET

Один объект вместо набора флагов

Closed и open — разные ветки union. Open target включает весь визуальный контракт, чтобы React не увидел новую страницу со старой геометрией. 

// Example open target: application-owned, deeply readonly
ShellSheetOpenTarget = {
  targetId: "flow:42:B.2",
  open: true,
  snapPoints: [
    { id: "b.compact", size: { type: "ratio", value: 0.48 } },
    { id: "b.expanded", size: { type: "ratio", value: 0.86 } },
  ],
  snapPoint: "b.expanded",
  presentation: "sheet",
  modality: "non-modal",
  draggable: true,
  contentResizeBehavior: "keep-snap-and-scroll",
  regions: {
    header: { key: "navigation", transition: "preserve" },
    body: { key: "location-details", transition: "crossfade" },
    footer: { key: "primary-actions", transition: "preserve" },
  },
  transition: { cause: "snap", direction: "snap", motion: "auto" },
};
targetId

Identity принятого доменного перехода. Создаётся приложением.

transitionId

Identity конкретной visual attempt. Создаётся Core.

settledTarget

Последний полностью показанный open target, а не второй store.

request → target → fact

Proposal, принятое состояние и наблюдаемый результат не смешиваются.

04 / TRANSACTION

Одна transition transaction

Registry, measurements, geometry и region layers сходятся в одном прерываемом coordinator. Никаких независимых таймеров в React-регионах.

  1. 01 Schedule

    Target, registry и observer events коалесцируются до одного work item.

  2. 02 Measure

    Все DOM reads: current rect, incoming regions, viewport и natural height.

  3. 03 Mutate / prepare

    Target attributes, invert geometry и hidden incoming styles пишутся вместе.

  4. 04 Animate

    На следующем frame стартуют Popup, Backdrop и changed regions.

  5. 05 Settle

    Пинится stable target, outgoing layers удаляются, token получает terminal fact.

05 / LAYOUT & MOTION

Один Popup, три региона

Header и Footer закреплены. Body — единственный scroll viewport. Sheet и dialog — две геометрии одной поверхности, а не два компонента.

Header · pinned
Body · scroll viewport
Footer · pinned
H

Natural target height

Header + intrinsic Body + Footer. Handle входит в Header и не прибавляется второй раз.

↕

Contained height motion

Popup изолирует layout через contain: layout paint. Высота анимируется сознательно, чтобы сохранить реальный scroll layout.

D

Sheet ↔ dialog

Coordinator измеряет old/new rect и анимирует translate + sizes. Scale запрещён: typography не искажается, Popup не remount.

A

Accessibility follows visuals

Неактивный transition layer получает inert и aria-hidden; в дереве доступности остаётся один смысловой слой.

06 / MODULE OWNERSHIP

Пять глубоких модулей

Каждый пакет владеет одним типом сложности. Верхние adapters используют нижние seams и не копируют их алгоритмы.

@shell-sheet/core

Atomic target, requests/facts, immutable snapshot, snap/release algorithms.

runtime deps: 0
@shell-sheet/dom

Registry, measurement transaction, coordinator, gestures, focus and modality.

→ core
@shell-sheet/motion

Только driver contract поверх motion/mini; без JSX и drag.

→ dom + motion/mini
@shell-sheet/effector

Attach application-owned $target, typed requests и visual facts.

→ core · Effector peer
@shell-sheet/react

Compound composition, Portal, refs и token-safe region registration.

→ core + dom · React peers
Запрещённая утечка: kind, uiContext, route, Query cache, тексты и demo-сценарии остаются в application/example. Core не знает о DOM; React не измеряет; Effector не получает pointer frames.
07 / REACT COMPOSITION

Compound API без visual logic

API повторяет Base UI Drawer-shaped anatomy и styling hooks, но расширяет её независимыми регионами и atomic target mode.

Три state mode

Atomic target, external controller или Base-shaped convenience. Одновременное смешивание режимов запрещено типами.

Root без DOM

Root владеет context/composition. Binding создаётся после refs; все measurements и animation остаются в DOM adapter.

Headless styling

render, function className/style, stable data-* и --drawer-*; bundled CSS отсутствует.

SSR-safe lifecycle

Cached snapshots через useSyncExternalStore; Portal v1 client-attached и становится видимым только после measurement.

09 / IMPLEMENTATION PATH

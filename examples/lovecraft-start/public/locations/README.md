# Generated location art

These five WebP assets were generated specifically for the Lovecraft atlas
example and optimized to 1440 px wide at WebP quality 82.

Shared prompt direction: original 1920s cosmic-horror environment concept art,
muted charcoal/tarnished-brass/oxidized-teal palette, restrained painterly
detail, wide 3:2 composition, clear architectural entrance, no people,
creatures, readable text, logos or watermark.

- `arkham.webp`: rain-dark university courtyard and old library at blue hour.
- `innsmouth.webp`: decaying harbor, black Atlantic water and warm dock door.
- `dunwich.webp`: ruined farmhouse, standing stones and hillside cellar door.
- `antarctica.webp`: blue glacier and monumental black-stone mountain gate.
- `dreamlands.webp`: moonlit basalt stair, cloud city and astronomical gate.

The original generated PNG files remain in the local Codex image-generation
output directory; the repository contains only the optimized demo assets.
